# FIFI Lab 交互与游戏主题统一设计

## 目标

在不改变首页已确认布局、背景波形、工具入口位置和猫猫光标的前提下，完成四项体验优化：

1. To-Do List 的任务内容随拉链开口真实显隐，不再穿过布面。
2. 默认待办改成不限定工作场景的中性引导。
3. 在右上角绿色区域增加符合首页材质语言的数字时钟。
4. 统一五个小游戏及其悬浮窗口的 UI，并为工具入口增加 C 版“蛋白传送门”加载动画和真实 URL 跳转。

## 不变范围

- 首页红、绿、黄三个鼠标响应背景区域保持现状。
- 两个工具入口的尺寸、位置和真实缩略图保持现状。
- 左侧五个游戏入口的布局保持现状。
- 猫猫鼠标拖尾保持现状。
- 五个游戏的规则、输入逻辑、存档、分数和排行榜协议不变。
- 品牌继续使用 `FIFI Lab / 菲菲实验站`，工具名继续使用 `FiFi 图片处理工具` 和 `FiFi 富文本转换`。

## 1. To-Do List 动态遮罩

### 表现

拉链的上沿、下沿和内容可见范围使用同一套几何数据。用户点击或拖动拉链时，任务区域不再整体淡入，而是被动态开口裁切：

- 开口只能容纳两条任务时，只显示两条。
- 开口经过第三条中部时，允许显示半条任务。
- 收回时沿相同路径反向裁切。
- 布面外的内容完全不可见，不能发生输入框或按钮穿过拉链边缘的情况。

### 实现边界

- 保留 `ZipperTodo` 现有贝塞尔曲线和拉链头运动方式。
- 从现有布面路径生成一个同步更新的 SVG `clipPath`，任务容器引用该裁切路径。
- 动画与鼠标拖动都只更新同一个 progress 值，拉链布面、拉链头和裁切路径不能各自维护进度。
- 完全收起后，任务输入框、勾选按钮、删除按钮和新增按钮退出键盘访问。
- 拖动中的部分展开状态只负责预览；任务编辑在完全展开后启用，避免半露条目被误触。
- `prefers-reduced-motion` 下取消缓动，但仍保留正确的最终裁切状态。

### 默认内容

首次访问且本地没有待办数据时，创建三条中性引导：

1. `今天要做什么呢？`
2. `想想今天要添加的计划`
3. `也可以给自己留一点空白`

已有用户的 `localStorage` 数据不能被新默认内容覆盖。

## 2. 右上角数字时钟

### 布局与视觉

- 时钟固定在右上角绿色背景区域内，位于顶部元信息下方。
- 不重画、不绑定或改变绿色背景波形；时钟作为独立前景层稳定定位。
- 主时间使用 24 小时制 `HH:MM:SS`，仅使用英文冒号，不显示“时、分、秒”字样。
- 下方显示完整日期和星期，例如 `2026年07月26日 · 星期日`。
- 时间是最大信息；日期明显可读但不与主时间争夺层级。
- 使用骨白、黑色粗描边、赭金或墨绿局部色和硬阴影，与首页搪瓷标签风格一致。

### 行为

- 首次渲染立即显示本机当前时间。
- 每秒更新，并按秒边界校准，避免长时间运行后逐渐漂移。
- 页面卸载时清理定时器。
- 时钟仅显示浏览器本地时间，不访问网络、不保存数据。

## 3. 游戏窗口与五个游戏主题

### 共用材质系统

`public/games/shared/game-shell.css` 提供五个游戏共同使用的主题变量：

- 深墨底：`#171411`
- 近黑描边：`#090806`
- 骨白面板：`#efe3c9`
- 浅纸色：`#f8efdc`
- 砖红：`#a43828`
- 墨绿：`#376b61`
- 赭金：`#d1a447`
- 莓果粉：`#c9798d`
- 深梅红：`#7e3048`

共用规则包括字体、粗描边、非对称圆角、硬阴影、按钮按下反馈、焦点状态、计分标签和说明文字层级。游戏画面中央保持清楚，不增加遮挡玩法区域的常驻面板。

### 外层悬浮窗口

首页 `GameWindow` 统一改为 FIFI Lab 风格：

- 骨白或浅纸色主体。
- 近黑三像素描边。
- 非对称圆角与砖红硬阴影。
- 标题栏使用深墨底，游戏识别色作为窄色条或标题标记。
- 重开和关闭按钮使用同一形状、描边和按压反馈。
- 现有游戏图标、标题、加载状态、失败重试和焦点恢复逻辑保持不变。

### 游戏识别色

- 2048：莓果粉。
- 数独：墨绿。
- 俄罗斯方块：赭金。
- 贪吃蛇：砖红。
- 合成大蛋白：深梅红。

识别色只承担标题标记、关键按钮、当前状态或得分强调。大面积背景、基础面板和边框仍使用统一材质，避免重新变成五套互不相关的页面。

### 各游戏处理

- 2048：保留现有滑动和合并动画，棋盘、分数卡和按钮换成共用材质；数字方块仍需保持等级可辨识。
- 数独：统一标题、换题按钮、棋盘外框、固定数字、输入数字和错误状态的层级。
- 俄罗斯方块：统一计分条、画布外框和触控按钮；方块颜色改为 FIFI Lab 色系的高对比组合。
- 贪吃蛇：统一计分条、画布外框和方向按钮；蛇、食物和棋盘底色采用站点色系并保持方向清晰。
- 合成大蛋白：保留每个蛋白等级的独立圆形填充色，统一外围舞台、危险线、按钮、失败面板和排行榜材质，不能破坏已确认的等级颜色区分。

### 缓存版本

五个游戏的入口 HTML、共享 CSS、各自 CSS 和本次修改的游戏脚本使用同一个新发布版本参数。首页 catalog 中五个 iframe 地址同步更新该版本，防止 GitHub Pages 或浏览器继续加载旧主题。

## 4. C 版“蛋白传送门”工具加载动画

### 动画内容

- 使用代码内绘制的全身蛋白矢量角色，不直接复用半身蛋白表情包。
- 左侧为砖红传送门，右侧为墨绿传送门。
- 蛋白从左侧钻入、在右侧出现，并带出“工具已送达”的小标签。
- 动画总时长约 1.5 秒，强动作只发生一次，不循环拖延跳转。
- `prefers-reduced-motion` 下改为短暂静态提示后跳转。

### 新标签页与 URL

现有 `about:blank + document.write + iframe` 方案废弃，改为仓库内独立过渡页：

- `FiFi 图片处理工具` 打开 `/fifi-tools/open-tool.html?tool=image-processor`。
- `FiFi 富文本转换` 打开 `/fifi-tools/open-tool.html?tool=rich-text`。
- 过渡页只接受预定义 tool id，通过内置映射取得真实工具网址，不接受任意外部 URL，避免形成开放跳转器。
- 动画完成后调用 `location.replace(realToolUrl)`，地址栏最终显示真实工具网址，后退时不回到过渡动画。
- tool id 无效时显示明确错误，并提供返回 FIFI Lab 首页的按钮。
- 浏览器阻止新标签页时，首页继续显示现有提示，不影响当前页面。

## 5. 组件与数据边界

- `ZipperTodo`：唯一持有拉链 progress 和待办数据，负责同步几何、遮罩和交互启用状态。
- `LabClock`：只负责本地时间格式化与每秒更新，不读取其他页面状态。
- `GameWindow`：从选中的 `GameItem` 读取识别色，负责统一窗口外壳，不修改 iframe 内玩法。
- `game-shell.css`：提供所有游戏共享主题变量和基础组件规则。
- 各游戏 CSS/脚本：只实现识别色和画布内容的必要覆盖。
- `open-tool.html` 及其脚本/样式：独立完成传送门动画和白名单跳转。
- `ToolGrid`：只负责打开具名过渡页和处理弹窗拦截，不再生成新页面 HTML。

## 6. 错误与降级

- To-Do 本地数据解析失败时使用三条中性默认内容；合法旧数据保持不变。
- 时钟格式化异常时至少显示数字日期和时间，不让组件影响首页其他内容。
- 不支持动画或启用减少动态效果时，拉链、时钟和工具跳转保持功能完整。
- 过渡页脚本未执行时提供真实工具链接作为可点击后备入口。
- 游戏主题加载失败不会改变游戏脚本；缓存版本保证新旧资源不交叉。

## 7. 验证标准

### 自动测试

- To-Do 默认内容、中性文案、数量上限、本地数据保留和收起后的不可访问状态。
- 拉链 progress 同时更新布面、拉链头和任务裁切路径。
- 时钟使用 24 小时制 `HH:MM:SS`，日期含年月日和星期，定时器按秒更新并清理。
- 两个工具入口打开正确的具名过渡页；过渡页只允许两个白名单 tool id，并在动画结束后替换为真实 URL。
- 五个游戏 iframe 使用同一新缓存版本，外层窗口接收各自识别色。
- 游戏逻辑测试、排行榜测试和已有 2048 动画测试全部继续通过。

### 浏览器验收

- 在桌面端逐段拖动拉链，截图确认两条、三条和半条任务的可见状态；反向收回同样无穿帮。
- 检查首页其他已确认元素的前后截图，确保背景、工具入口、游戏入口和猫猫光标没有发生非授权变化。
- 检查时钟在绿色区域内不遮挡标题、工具或顶部元信息。
- 逐个打开五个游戏，检查外层窗口统一、内部识别色清楚、玩法区域无遮挡、桌面和移动端无滚动条。
- 从首页点击两个工具，检查传送门动画、过渡页非空 URL、最终真实工具 URL 和页面成功加载。
- 正式发布后必须从 GitHub Pages 首页入口重新验证，不能只检查游戏或过渡页直链。
