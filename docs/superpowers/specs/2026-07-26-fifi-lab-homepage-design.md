# FIFI Lab 首页正式版设计

## 目标

将已确认的全屏视觉原型迁入正式 React 站点，并保留现有小游戏悬浮窗口、合成大蛋白排行榜和 GitHub Pages 发布链路。

## 品牌与文案

- 站点总品牌统一使用 `FIFI Lab`。
- 中文语义副标题使用“菲菲实验站”。
- 首页 slogan 固定为“一些能让生活省点力气的小实验。”
- 两个产品入口保持 `FiFi 图片处理工具` 与 `FiFi 富文本转换`，不得批量改成全大写。
- 游戏区标题保持“智力检测站”。

## 桌面布局

- 页面占满视口，外圈使用厚重双层框线。
- 背景保留三个受鼠标影响、持续呼吸变形的红、绿、黄抽象色块。
- 智力检测站竖排固定在左侧，五个游戏入口集中在同一区域。
- 两个工具入口位于游戏区右侧，使用真实网页缩略图、厚描边和实体阴影。
- 右侧保留大面积呼吸空间，用于 `FIFI Lab` 标题、中文副标题和 slogan。
- 不恢复此前已否定的大渐变、普通圆角卡片或“来我家”式房间文案。

## 工具入口

- 使用真实工具缩略图，不直接使用蛋白表情包充当工具图标。
- 点击时立即打开新标签页，并以当前缩略图从卡片尺寸放大到工作区尺寸；目标页面载入后渐隐融合，避免尺寸突变闪烁。
- 弹窗被阻止时显示站内提示，不修改当前页。

## 游戏入口与窗口

- 首页前四个游戏使用玩法语义图标：2048、数独、俄罗斯方块、贪吃蛇。
- 合成大蛋白使用圆形等级蛋白图标。
- 五个入口继续调用现有 `GameWindow`，游戏在站内悬浮窗口打开。
- 不修改游戏源码、排行榜协议或当前游戏尺寸。

## 拉链 To-Do

- 位于左下区域，整体离页面左边和底框保留间距。
- 收起时只展示弧形拉链、独立标题白条与统计文字。
- 标题白条沿拉链同弧度上移，完整露出拉链齿；`TO-DO LIST` 与统计文字垂直居中在白条内。
- 统计格式为“我有 N 条待办 · M 条完成”，N 是总数，M 是勾选完成数。
- 拉链可点击切换，也可沿曲线拖拽；松手后按 48% 阈值自动吸附到打开或关闭状态。
- 展开时任务从第一条开始依次出现；关闭时最后一条先退场、第一条最后退场。
- 新增按钮位于扇形区域右下角；最多 8 条，每条最多 50 字。
- 数据只保存在当前浏览器 localStorage，不发送到服务器。

## 鼠标交互

- 保留工具卡片的轻微透视倾斜和扫光。
- 保留猫猫头矢量拖尾与小圆点光标。
- `prefers-reduced-motion` 下关闭背景连续动画、猫猫拖尾和非必要过渡。

## 响应式与无障碍

- 桌面宽度优先保证单屏完整展示。
- 窄屏允许页面纵向延展，确保没有水平溢出且所有工具、游戏均可访问。
- 所有入口使用原生链接或按钮；拉链按钮维护 `aria-expanded` 和清晰的中文标签。
- 输入框、完成按钮、删除按钮均提供可访问名称。

## 验收

- 组件测试覆盖品牌、工具名、五个游戏、To-Do 总数/完成数、8 条上限和开合状态。
- E2E 覆盖关键宽度下无水平溢出、左侧游戏区、工具缩略图、拉链标题与桌面单屏布局。
- 运行 `npm test`、`npm run test:games`、`npm run build` 与首页 E2E。
- 浏览器截图确认背景、入口、标题白条、拉链和展开面板没有遮挡。

## 范围外

- 本次不修改五个游戏的玩法。
- 本次不修改 Cloudflare Workers、D1 或排行榜数据。
- 本次不新增账号、同步或跨设备 To-Do。
